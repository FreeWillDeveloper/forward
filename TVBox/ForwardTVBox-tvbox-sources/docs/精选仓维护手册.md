## 二、源选取逻辑（三级闸门，缺一不可）

### 闸门 1：目录接口可拉取
- 调用 `{api}?ac=list`，必须返回 200 + 合法 JSON + `class` 数组（分类）
- 死链/超时/DNS 不通 → 直接排除

### 闸门 2：资源量足够大
- 每个分类下资源数要够大（合格线 ≈ 3~5 万+）
- 太小（几千部）的源没有存在价值，排除

### 闸门 3：播放链接必须是 m3u8 直链 + 分片可下载（★最重要）
- 取详情页 `ac=detail` → 检查 `vod_play_url` 是否返回 **m3u8 直链**
- 直链要能下载**首个分片**（实测下载成功 + 有一定字节量）
- 支持 master playlist 嵌套追踪（`#EXT-X-STREAM-INF` 里还有一层真实 m3u8）
- **网页链接源一律排除**——返回优酷/腾讯/爱奇艺官方网页、或本站播放页跳转的，TVBox 播不了（官采/建安/haiwaikan/快帆/量子的老毛病）

### 通过三闸门后还要看可用性
- 多线源优先（如玩家有多个播放线路）
- 长期稳定域名优先；接口经常换域名的源谨慎进仓

| type | 含义 | 精选仓现状 |

## 四、playerType 铁律（v8 事故教训）

**合法值只有：`0=系统播放器 1=ijk 2=exo 10=mxplayer -1=默认`**

> ❌ `playerType=3` 非法！曾因误写 3 导致**整个仓解析失败**（用户报"拉不到目录"），v8 回滚。

- type=1 的 CMS 源：不写 playerType（留空）或写合法值，推荐留空/0
- type=3 的 CSP 源：写 2（exo）通常最稳

---

## 五、筛选功能（filter）真相 —— 千万别再被坑

**结论先行：TVBox 对 type=1 CMS 源的筛选，只能来自接口本身**（`ac=list` 响应里的顶层 `filters` 字段，按分类 id 映射），**不是配置里能加的**。

- 实测 45+ 个 CMS 源（含 qist/多多/博客园接口），**全部不返回 filters** → 所以 CMS 源在 TVBox 里都没有筛选按钮
- 只有 **type=3 CSP 源**（如玩偶哥哥）由 jar 内置筛选，才有类型/年代/排序
- `filterable: 1` 只是开关，接口不返回 filters 就没用（加了无害）

**所以：别再试图给 CMS 源加筛选了，做不到。用户要用筛选就用玩偶哥哥。** 除非找到接口自带 filters 的采集站（目前没找到）。

## 十一、踩坑备忘录（血泪史）

1. **playerType=3** → 整仓解析失败（v8 事故），合法只有 0/1/2/10/-1
2. **网页链接源** → 永远播不了，别被"资源量大"骗（建安 6.3 万照样排除）
3. **Python 编码坑** → 暴風中文 URL 在 Python 触发 ascii 报错是**测试脚本**问题，TVBox 实际能播，别冤枉好源
4. **filterable=1 不等于有筛选** → 筛选数据只能来自接口 filters 字段，CMS 源普遍没有
5. **spider 字段别动** → fan.jar 必须真实存在，MD5 别改
6. **热播要用 csp_AppTTGuard**（饭太硬版），不是全量仓里的 csp_AppTT；ext 用 qist 配置里的 base64
7. **拉取一定要带 gh-proxy.com 前缀**，直连 raw.githubusercontent.com 在国内经常失败
8. **新源进仓前必测播放**，不能只看"能出目录"（目录=ac=list 有 class，播放=详情返回 m3u8 直链，两码事）

## 十二、直播源（lives）

**精选仓 2026-08-11 起含 2 个直播源：**

| key | 说明 | 地址 |
|---|---|---|
| IPTV4-直播 | txt 格式，780 频道（央视/卫视/地方台），国内直连 | https://live.zbds.top/tv/iptv4.txt |
| IPTV4-M3U | m3u 格式，带台标+EPG 节目单 | https://live.zbds.top/tv/iptv4.m3u |

**配置要点：**
- lives 数组放顶层（和 sites/parses 平级），每个元素 `type: 0`（直接读 url，TVBox 用 TxtSubscribe 自动识别 txt/m3u），`playerType: 2`（exo 播放器）
- 数据源来自 GitHub 项目 vbskycn/iptv（每 6 小时自动扫描验证更新，IPv4/IPv6 双栈）
- 源地址本身稳定（live.zbds.top），但**内部频道 IP 会变**——某台看不了时重新拉一次源即可

**坑：**
- 直播频道地址绝大多数是 `http://公网IP:端口/tsfile/live/xxx.m3u8`，直连延迟取决于本地网络和该 IP 的稳定性；换台卡顿时优先换频道内其他地址（txt 里同台多名）
- TVBox 会把直播地址存到本地设置（Hawk LIVE_URL），改配置后若仍显示旧源，去设置里清掉直播地址再重拉
- 备选直播源仓库：dongyubin/IPTV（4.3k star）、vbskycn/iptv（首选，更新最勤）
