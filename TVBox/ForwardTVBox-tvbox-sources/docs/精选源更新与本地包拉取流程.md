# 精选源更新 & 本地包拉取流程（2026-08-18 整理）

## 一、仓库三仓自动更新现状

| 配置 | 文件 | 更新方式 | 频率 |
|------|------|----------|------|
| 全量单仓 | tvbox.json | GitHub Actions（workflow: auto-update.yml） | 每天 08:00 + 每次 push 触发 |
| 多仓 | urls.json | 同上（update.py 一起生成） | 同上 |
| 精选仓 | curated.json | **人工手动维护**（封哥/虾弟精选） | 需要时 |
| 直播源 | live/iptv4-fast.txt | 本地 Hermes cron"直播源每日测速优选" | 每天 16:00 |
| 精选仓本地版 | curated-local.json | 人工+打包脚本生成（jar 指向本地文件） | 与精选仓同步 |
| 订阅聚合 | subscribe.json | 基本不动 | 极少 |

## 二、精选源更新流程（手动，核心步骤）

```text
1. 修改 curated.json（增删源/调参数）
   ├─ 新源先用 Curl/脚本验证：目录可拉 → 资源量≥3-5万 → m3u8直链可播
   ├─ Guard 源（csp_XxxGuard）必须依赖存在的 jar（fan.jar/custom_spider.jar/pg.jar）
   └─ playerType 铁律：只允许 0/1/2/10/-1，写 3 会导致整个配置加载失败
2. 同步 curated-local.json（本地版，jar 改相对路径 ./xxx.jar）
3. git commit + push（直连不稳时用代理：git config http.proxy http://127.0.0.1:7890，用完撤）
4. 验证线上：curl ghfast 拉 curated.json → 数源数、验 spider md5
5. 重打包（如需要发本地包）：
   python C:/Users/tongtong/tools/update_tvbox_local_pack.py
   → 生成 C:\Users\tongtong\Desktop\tvbox-sources-YYYYMMDD.zip
```

## 三、本地包（离线包）拉取流程

本地包用途：**GitHub 抽风/无网备份/电视导入**。日常看电视直接用在线订阅地址，不需要包。

### 场景 A：日常在线订阅（推荐，不需要包）
```text
电视/手机影视仓 配置地址：
https://ghfast.top/https://raw.githubusercontent.com/jifeng250/tvbox-sources/main/curated.json
```
- 每次都拉最新源，自动更新，无需手动
- 电视更新源失败时：清缓存 + 强杀 TVBox 重开

### 场景 B：手机/电视离线包（GitHub 挂了/没网时）
```text
1. 手机端：打开 PWA 下载页（可加入主屏幕当 App 用）
   https://jifeng250.github.io/tvbox-sources/
   → 点「下载最新包」→ zip 存到手机 Download
2. 电视端（U 盘/局域网任选）：
   ├─ U 盘：手机复制 zip → U 盘 → 插电视
   └─ 局域网：手机装 ES 文件浏览器/小白文件管理器开共享 → 电视访问手机目录
3. 影视仓导入：设置 → 配置管理 → 添加 → 本地文件 → 选解压后的 curated-local.json
   ⚠️ 必须选 curated-local.json（jar 指向本地，断网也能加载目录）
```

### 场景 C：在电脑边时（最快）
```text
1. 双击桌面「更新TVBox本地包.bat」（3 秒重新打包，含最新源+直播）
2. 或飞书喊虾弟：「发最新包」→ 直接收到 zip
3. 拷贝到手机/电视
```

## 六、手机端 App（PWA 下载页）

- 地址：https://jifeng250.github.io/tvbox-sources/
- 手机浏览器打开 → 右上角菜单「添加到主屏幕」→ 桌面出现图标，点开=App
- 功能：显示最新包版本/日期 → 一键下载 zip → 按场景 B 流程传给电视
- 依赖：仓库 Pages 已开启，zip 随手动打包自动更新（update_tvbox_local_pack.py 同步 version.json）

## 六、加新源必查（防踩坑清单，2026-08-18 沉淀）

**新增任何 jar 源（api 以 csp_ 开头）时：**
1. **必须带源级 jar**（指向 ghfast 加速的仓库 jar，如 pg.jar）或确认顶层 spider 覆盖
2. **PG 盘搜类源必须带 ext**（含 lib/token.json）——缺 ext = 源加载失败/目录空白（历史大坑：
   2026-08-18 加 10 个 PG 源漏 ext 导致全部加载不出）
3. **必须 pass 校验脚本**：`python tools/validate_config.py`（独立可跑，update_tvbox_local_pack.py
   打包前自动强制校验，不通过拒绝打包）
4. playerType 只允许 0/1/2/10/-1
5. jar 引用必须带 md5（与仓库内 jar 实际 md5 一致）
6. lives 直播源必须配 epg + logo（112114 已挂，现用 51zmt EPG + wswtv 台标）

## 七、故障排查速查

| 现象 | 处理 |
|------|------|
| 电视源目录空白 | 清缓存 + 强杀 TVBox 重开；不行就更新 TVBox 版本 |
| 在线订阅拉不到 | 换 gh-proxy.com 前缀；或临时用本地包 |
| Guard 源集体白屏 | 跑 check_fan_jar_update.py 同步 jar → 重打包 |
| 本地包导入后 jar 源空 | 确认导入的是 curated-local.json 不是 curated.json |
