# 소비자용 AI 제품 시나리오 참고

기업용 제품은 비용과 업무 효율을 먼저 묻는 경우가 많습니다. 일반 사용자를 위한 제품은 조금 다릅니다. 같은 기능이라도 사용자가 편안함, 재미, 성취감 같은 감정을 느껴야 다시 찾아옵니다.

이 부록은 그대로 복사할 정답 목록이 아닙니다. 관심 있는 생활 장면을 고른 뒤, 실제 사용자를 만나 문제를 확인하기 위한 출발점입니다.

## 1. 먼저 사용 장면을 한 문장으로 적기

“AI 일기 앱”처럼 기능만 적지 말고, 누가 언제 왜 여는지까지 적어 보세요.

```text
혼자 사는 직장인이 퇴근 후 마음을 정리하고 싶을 때 여는 5분 감정 일기
```

이 한 문장에 사용자, 시간, 상황, 기대하는 변화가 들어가면 첫 화면과 핵심 기능을 정하기 쉬워집니다.

## 2. 일상에서 찾을 수 있는 방향

| 장면 | 만들 수 있는 첫 기능 | 확인할 질문 |
| --- | --- | --- |
| 생활 방식 | 아침 루틴, 주말 계획, 취침 전 오디오 | 사용자가 이미 어떤 방법으로 하루를 정리하는가? |
| 감정 돌봄 | 감정 기록, 호흡 안내, 대화 정리 | 의료 조언으로 오해될 표현은 없는가? |
| 오락 | 인터랙티브 소설, 게임 NPC, 개인 팟캐스트 | 5분 뒤에도 계속할 이유가 있는가? |
| 개인 성장 | 습관 퀘스트, 학습 동료, 성장 회고 | 기록이 쌓일수록 가치가 커지는가? |
| 소셜 | 대화 주제, 모임 진행, 글 초안 | 사용자의 말투와 관계를 존중하는가? |
| 창작 | 글감, 사진 구도, 음악 분위기 추천 | 결과를 사용자가 다시 편집할 수 있는가? |
| 여행 | 산책 경로, 여행 일기, 혼자 여행 체크 | 위치와 일정이 달라도 쓸 수 있는가? |
| 건강 | 운동 격려, 식사 아이디어, 수면 습관 | 진단이나 치료처럼 보이지 않는가? |
| 학습 | 상황별 언어 연습, 독서 질문, 지식 퀴즈 | 답만 주지 않고 학습을 돕는가? |
| 관계 | 대화 준비, 가족 안부, 갈등 정리 | 상대방을 조종하는 문구가 없는가? |
| 반려동물 | 행동 기록, 돌봄 일정, 추억 이야기 | 전문가 진료가 필요한 상황을 구분하는가? |
| 재정 | 소비 감정 기록, 저축 목표, 금융 기초 | 수익을 보장하는 것처럼 말하지 않는가? |
| 직업 | 면접 연습, 성과 회고, 부업 탐색 | 개인 정보와 회사 자료를 안전하게 다루는가? |
| 집 | 작은 공간 배치, 정리 동행, 계절 꾸미기 | 사진 없이도 기본 기능을 쓸 수 있는가? |
| 음식 | 1인 식사, 남은 재료 조합, 초보 요리 | 알레르기와 식이 제한을 먼저 묻는가? |
| 옷차림 | 날씨별 코디, 캡슐 옷장, 기존 옷 재조합 | 구매를 강요하지 않고 가진 옷을 활용하는가? |

## 3. 한 방향을 작은 제품으로 줄이기

예를 들어 “도시 산책 도우미”를 골랐다면 처음부터 예약, 결제, 친구 기능을 모두 만들 필요는 없습니다. 첫 버전은 다음 한 흐름이면 됩니다.

1. 사용자가 시간과 원하는 분위기를 고른다.
2. AI가 짧은 산책 경로와 세 장소를 제안한다.
3. 사용자가 한 곳을 교체한다.
4. 최종 경로를 저장한다.

AI에게는 이렇게 짧게 요청할 수 있습니다.

```text
도시 산책 도우미의 첫 화면을 만들어 주세요. 시간과 분위기를 고르면 세 장소를 추천하게 해 주세요.
```

첫 화면이 되면 다음 기능을 한 가지씩 더합니다.

```text
추천 장소 하나를 다른 장소로 바꾸는 버튼을 추가해 주세요.
```

## 4. 소비자용 제품을 점검하는 기준

기능이 많다고 좋은 제품은 아닙니다. 다음 네 가지를 실제 사용자에게 보여 주고 확인하세요.

- **바로 이해되는가:** 설명 없이 첫 화면의 용도를 알 수 있는가?
- **금방 보상이 오는가:** 첫 사용 1분 안에 쓸 만한 결과가 나오는가?
- **통제권이 있는가:** AI 결과를 고치고 삭제할 수 있는가?
- **안전한가:** 건강, 감정, 재정처럼 민감한 분야에서 한계를 밝히는가?

관심 있는 장면 하나를 선택해 사용 상황을 한 문장으로 적고, 가장 짧은 사용 흐름을 먼저 만드세요. 그다음 실제 사용자 세 명에게 보여 주고 “좋아 보이나요?” 대신 “마지막으로 이런 상황을 언제 겪었나요?”라고 물어보면 아이디어가 실제 문제에 가까워집니다.
