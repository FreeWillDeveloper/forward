# 웹페이지에서 실제 프로그램, AI 네이티브 제품으로

Vibe Coding은 흔히 “웹페이지를 만들어 줘”라는 말에서 시작합니다. 화면이 나타난 뒤에는 버튼을 더 늘리기보다 데이터를 저장하고, 실제 사용자의 일을 끝내고, 마지막에 AI가 작업에 참여하도록 발전시켜야 합니다.

![웹페이지에서 실제 프로그램과 AI 네이티브 제품으로 가는 길](../../../../zh-cn/stage-3/cross-platform/ai-native-creator/images/creator-journey.svg)

## 1. 먼저 공유할 수 있는 웹페이지를 만든다

모호한 아이디어를 화면 구조로 바꾸고, 자신의 판단으로 고치고, 다른 사람이 열 수 있는 URL로 배포합니다. 처음 방문한 사람이 목적을 이해하고, 휴대폰에서도 동작하며, 보이는 버튼이 모두 실제 기능을 가지면 첫 단계가 끝난 것입니다.

## 2. 페이지를 프로그램으로 만든다

실제 프로그램에는 네 가지가 필요합니다.

1. 저장·수정·삭제할 수 있는 실제 데이터
2. 계정, 업무 규칙, 비밀 정보를 보호하는 백엔드
3. 빈 입력, 끊긴 네트워크, 실패한 요청에서 돌아오는 방법
4. 개발자의 컴퓨터 없이 설치하고 업데이트할 수 있는 배포

웹사이트, 미니프로그램, 데스크톱 앱, 브라우저 확장 중 무엇이든 실제 일을 안정적으로 끝내면 완성된 프로그램입니다.

## 3. AI 네이티브 제품으로 나아간다

채팅 창 하나를 붙였다고 AI 네이티브가 되는 것은 아닙니다. AI 네이티브 제품은 사용자의 목적을 이해하고, 필요한 정보만 읽고, 통제된 도구를 사용하며, 중요한 행동 전에 확인을 받습니다.

- 일반 코드는 확정된 규칙, 데이터, 권한을 맡습니다.
- AI는 언어, 생성, 불완전한 정보를 맡습니다.
- 사람은 목표, 위험한 결정, 최종 확인을 맡습니다.

## 4. 지금 있는 단계에서 한 걸음만 간다

공개 페이지가 없다면 하나를 배포합니다. 예쁜 Demo가 많다면 하나를 골라 실제 데이터, 백엔드, 오류 처리를 넣습니다. 이미 완성된 프로그램을 만들 수 있다면, 사람이 해석하던 한 단계에만 AI를 붙이고 승인 절차를 남깁니다.

**웹페이지는 아이디어를 보이게 하고, 프로그램은 사용자의 일을 끝내며, AI 네이티브 제품은 소프트웨어가 그 일에 참여하게 합니다.**

검증할 수 없는 복잡한 Agent보다 작지만 믿을 수 있는 앱이 더 가치 있습니다.
