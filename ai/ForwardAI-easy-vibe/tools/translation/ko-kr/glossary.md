# 번역 용어집 (Translation Glossary)

> stage-1 zh↔ko 정렬로 시드. 새 용어는 번역 PR에서 논의한 뒤 승인 시 편입.

## 원칙
- 아래 표준 용어를 무조건 사용한다. 같은 개념을 다른 단어로 번역하지 않는다.
- "원문유지"는 번역하지 않는다. "외래어표기"는 정해진 한글 표기를 쓴다.
- 금지어가 떠오르면 표준 용어로 치환한다.
- **업계 표준어는 웬만하면 영문 유지**: 한국어로 옮겼을 때 어색하거나 의미가 애매해지는 업계 표준 용어(text-to-image, image-to-image 등)는 **영문 그대로** 둔다. 억지 음차·직역(문생도, 텍스트→이미지 등)은 금지.

## 카테고리 메모
- **痛点 3종 세트(痛点/爽点/痒点)**: stage-1 finding-great-idea에서 "문제점 / 만족점 / 가려운 지점"으로 일관 번역, 괄호로 원어(Pain/Delight/Itch Point) 병기. 일반 문맥의 "痛点"도 "문제점"으로 통일.
- **Agent / 智能体**: **"에이전트"로 통일 확정**(2026-05). 표준=에이전트, 금지어=상담원·대리인·지능체. stage-2 index·사이드바의 기존 "에이전트" 표기 그대로 유지. (stage-1의 "Agent(지능체)" 표기는 향후 재방문 시 정합화 대상)
- **接口의 이중성 (확정)**: 통신/API 맥락 → "API", 화면/UI 맥락 → "인터페이스"로 구분 적용.
- **중국 고유명사 표기 혼재**: 대부분 영문 원문 유지(ByteDance 등), "小红书"만 음차(샤오훙슈). 인명도 로마자(梁文锋→Liang Wenfeng). 정책 확정은 candidates 참고.
