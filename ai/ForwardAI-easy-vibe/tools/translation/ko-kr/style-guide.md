# 한국어 자연스러움 가이드 (DO / DON'T)

> 사람이 **직접 검수하며 고친 실제 수정**에서 뽑은 직역투→자연스러운 표현 규칙입니다.
> glossary.md가 **단어** 룰이라면, 이 파일은 **문형·표현** 룰입니다. 한국어 번역 기여자는 번역 전에 읽고 적용합니다.

## 정착 패턴 (필독 · 매 번역에 적용)

| # | 유형 | ❌ DON'T (직역투) | ✅ DO (자연스러운 한국어) | 근거 |
|---|------|------------------|--------------------------|------|
| S1 | 접속 구조 `并不是 A 而是 B` | "~이 아닙니다. 바로 ~것입니다" (문장 끊김) | "~이 아니라 ~것입니다" (한 흐름) | lovart §4 |
| S2 | 명사 종결 직역 | "…라는 감각입니다." (앞 문장과 끊겨 붕 뜸) | "…라는 감각 말입니다." (앞에 연결) | lovart §4 |
| S3 | `当 … 时` 직역 | "입력이 ~가 되면" (피동·번역체) | "~를 입력하면" (능동) | lovart §3 |
| S4 | 외래어 남발 | 文章 → "아티클" | "글 / 한 편의 글" | lovart §3 |
| S5 | `缺乏 … 能力` 직역 | "~능력이 부족한 결과로 이어집니다" | "~을 못 합니다 / 아우르지 못합니다" | lovart §3 |

## 일반 원칙 (위 패턴의 바탕)
- **끊지 말 것**: 원문이 한 호흡(`并不是…而是`, `虽然…但是` 등)이면 한국어도 한 문장으로 잇는다. 마침표로 끊어 명사문이 붕 뜨게 두지 않는다.
- **능동·서술 우선**: "~가 되면/~되는 것이다" 같은 번역체보다 "~하면/~한다"로.
- **외래어는 정착된 것만**: 정착 외래어(프롬프트·컨텍스트 등, glossary 참조)는 쓰되, 굳이 음차할 필요 없는 일반어(文章=글)는 한국어로.
- **직역 명사구 풀기**: "~능력이 부족한 결과로 이어진다" → "~을 못 한다"처럼 동사로 푼다.
